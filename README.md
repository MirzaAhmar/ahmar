# Ahmar Portfolio

Modern, responsive portfolio built with Next.js, TypeScript, and Tailwind CSS.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Checks

```bash
npm run lint
npm run build
```

Project content is split into typed data in `data/projects.ts` and reusable UI in `components/portfolio.tsx`. Screenshots are served from `public/images`.
